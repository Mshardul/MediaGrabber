# Security

## Reporting a vulnerability

Report security vulnerabilities through GitHub's **"Report a vulnerability"** button on the Security tab of this repository. Do not open a public issue for a vulnerability.

## What to include

Include enough to reproduce the issue:

- What happened, and what you expected instead
- The site or link involved, if any
- The MediaGrabber version (About → version)
- Steps to reproduce, in order
- A Diagnostics export if relevant (Preferences → Diagnostics → Share diagnostic bundle — it contains logs and health data, no account or cookie data)

We will acknowledge your report and work with you on a fix before any public disclosure.
