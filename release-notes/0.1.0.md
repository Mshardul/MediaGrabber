MediaGrabber 0.1.0 — hello, world!

Found a video you like? Paste the link. MediaGrabber fetches the title, shows a progress bar, and says Saved when your file is ready. One click on Reveal in Finder and it's right there.

What it can do:

- Run several downloads at once. Pause one, cancel another, and let the rest carry on.
- Take a whole playlist. Paste it, tick the videos you want, and skip the rest.
- Save just the sound as m4a or mp3, for when you only need the music.
- Ask you to sign in only when a site actually needs it. No pestering otherwise.

This first release runs on Apple Silicon Macs with macOS 14 or later. The README has the install steps. Your Mac blocks the first launch until you allow it, and the README shows exactly where to click.

It's the first one, so if something acts strange, tell us. We'd love to fix it.
