MediaGrabber 0.1.0

MediaGrabber downloads a video from a link you paste. It shows the title, a progress bar, and Saved when the file is ready, with a button to reveal it in Finder. You can keep several downloads going, pause or cancel one, and paste a playlist and pick which items to keep. Sign-in is only suggested when a site needs it.

This release runs on Apple Silicon Macs with macOS 14 or later. Follow the install steps in the README to get started.
